# Project Overview

## English
This project, named **Makani**, is a comprehensive solution designed to manage various business operations. It encompasses multiple modules that facilitate streamlined management of Inventory, Sales, Purchases, Customers, Suppliers, General Ledger, and System Settings.

### Project Structure
- **Inventory**: Manage stock levels, suppliers, and product information.
- **Sales**: Process sales transactions, manage customers, and create sales reports.
- **Purchases**: Handle purchase orders and supplier management.
- **Customers**: Maintain customer records and manage interactions.
- **Suppliers**: Oversee supplier data and manage vendor relationships.
- **General Ledger**: Keep track of all financial transactions.
- **System Settings**: Configure application settings and user roles.

### Features
- User-friendly interface for seamless interaction.
- Real-time data synchronization for accurate inventory tracking.
- Comprehensive reporting and analytics capabilities.
- Modular architecture for easy maintenance and upgrades.

### Technology Stack
- **Backend**: C#, SQL Server, ASP.NET Core Web API
- **Frontend**: React
- **Desktop Application**: WPF
- **Mobile Application**: MAUI Mobile

### Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/mhhhh2418-sudo/makani.git
   cd makani
   ```
2. Install required packages:
   ```bash
   dotnet restore
   ```
3. Run the application:
   ```bash
   dotnet run
   ```
   For desktop and mobile applications, please refer to the respective documentation.

## العربية
هذا المشروع، الذي يُعرف باسم **Makani**، هو حل شامل مصمم لإدارة العمليات التجارية المختلفة. ويشمل عدة وحدات تسهل الإدارة السلسة للمخزون، المبيعات، المشتريات، العملاء، الموردين، دفتر الأستاذ العام، وإعدادات النظام.

### هيكل المشروع
- **المخزون**: إدارة مستويات المخزون، الموردين، ومعلومات المنتجات.
- **المبيعات**: معالجة معاملات المبيعات، إدارة العملاء، وإنشاء تقارير المبيعات.
- **المشتريات**: التعامل مع طلبات الشراء وإدارة الموردين.
- **العملاء**: الحفاظ على سجلات العملاء وإدارة التفاعلات.
- **الموردون**: الإشراف على بيانات الموردين وإدارة علاقات البائعين.
- **دفتر الأستاذ العام**: تتبع جميع المعاملات المالية.
- **إعدادات النظام**: تكوين إعدادات التطبيق وأدوار المستخدمين.
